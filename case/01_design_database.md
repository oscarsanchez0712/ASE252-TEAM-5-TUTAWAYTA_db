# 🧩 Diseño de Base de Datos - Tuta Wayta

## 📌 Descripción General
La base de datos del sistema Tuta Wayta ha sido diseñada para gestionar la venta de productos derivados de la pitahaya, permitiendo administrar usuarios, productos, pedidos y mensajes de contacto.

El diseño busca garantizar integridad, eficiencia y escalabilidad en el manejo de la información.

![Diseño Base de Datos](../image/_ASOCIACION_DE_PITAJAYA_-_TUTAWAYTA_(San_Vicente)_Physical_Export-2026-04-14_19-41.png)


## 🏗️ Diseño de Base de Datos
El sistema se compone de las siguientes tablas principales:

- usuarios
- productos
- pedidos
- detalle_pedido
- contacto

Estas tablas están relacionadas mediante claves primarias y foráneas para asegurar la integridad referencial.
